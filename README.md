Me migro de github a codeberg, congelando este proyecto en github por completo. 
Puedes encontrar la página de presentación del nuevo proyecto [aquí](https://mcupp.codeberg.page/).
En [este](https://codeberg.org/mcupp) repositorio de codeberg puedes encontrar este proyecto de github. Como ha crecido más de lo que pensaba
he aprovechado para partirlo en partes. 
En principio he descompuesto el proyecto en:

* [std](https://codeberg.org/mcupp/std) que tiene el estandar de C++
* [atd](https://codeberg.org/mcupp/atd) cosas genéricas de C++
* [micro](https://codeberg.org/mcupp/micro) con los traductores de los avrs.
* [devices](https://codeberg.org/mcupp/devices) con los traductores del resto de dispositivos de hardware.
* [drivers](https://codeberg.org/mcupp/drivers) capa genérica basada en `devices`
* [pli](https://codeberg.org/mcupp/pli) bibliotecas genéricas para usar en diferentes proyectos
* [projects](https://codeberg.org/mcupp/projects) diferentes proyectos
* [mcu](https://codeberg.org/mcupp/mcu) estructura que uso localmente con todo el código anterior.
